2. Result Schema (v1.0.0)

Every benchmark run must produce a JSON result conforming to schemas/result.schema.json. Required top-level fields:

📋 Required Fields

schema_versionMust be "1.0.0"
suite_versionVersion of benchmark suite
created_atISO 8601 timestamp
run_idUnique run identifier
input_identityReproducibility hashes (see below)
environmentRuntime environment info
contract_versionWhich contract was evaluated
dataset_manifestDataset provenance info
resultsPer-product benchmark results
raw_artifactsPaths to raw output files
failure_accountingError/skip tracking
signatureHMAC integrity signature

🔐 Input Identity (Reproducibility)

repositorySource repo URL
repository_commitGit commit SHA
artifact_digestSHA256 of built artifact
model_hashHash of model weights
dataset_hashHash of dataset used
configuration_hashHash of config files
dependency_lock_hashHash of lockfile
seedsRNG seeds for reproducibility

4. Evidence Integrity

Every benchmark result is cryptographically signed to prevent tampering and ensure audit trail integrity.

🔒 HMAC Signature

Algorithm: hmac-sha256

Process:

  1. Result payload serialized with stable_json() (sorted keys, no whitespace)
  2. SHA-256 of payload computed → payload_sha256
  3. HMAC-SHA256 signed with secret key → signature.value

Verification: hmac.compare_digest(expected, actual)

🧬 Artifact Digests

Tracked Hashes (input_identity):

artifact_digestBuilt package/wheel SHA-256
model_hashModel weights SHA-256
dataset_hashTest fixtures SHA-256
configuration_hashConfig file SHA-256
dependency_lock_hashLockfile SHA-256

All hashes use SHA-256. Any mismatch indicates the run is not reproducible from declared inputs.

✅ Integrity Check Workflow

# Verify a result file's signature
mlsec-bench verify results/latest.json

# Check: payload_sha256 matches recomputed hash
# Check: HMAC signature matches with stored key
# Check: input_identity hashes match current repo state

5. Running Benchmarks

Prerequisites

# Install the benchmark suite
pip install -e .[dev]

# Or install from the repo root
cd mlsec-benchmark-suite
pip install -e .

CLI Commands

# Run all smoke benchmarks (portfolio-smoke-v1 contract)
mlsec-bench run --contract portfolio-smoke-v1

# Run a specific product benchmark
mlsec-bench run --contract portfolio-smoke-v1 --product hf_scanner

# Verify result integrity
mlsec-bench verify results/latest.json

# List available contracts
mlsec-bench list-contracts

# Run tests
pytest tests/ -v --cov --cov-fail-under=80

CI Integration

# GitHub Actions example
- name: Run MLSec Benchmarks
  run: |
    pip install -e .[dev]
    mlsec-bench run --contract portfolio-smoke-v1
    mlsec-bench verify results/latest.json
